# Security

Report suspected vulnerabilities privately to [hello@bento.cat](mailto:hello@bento.cat). Include the affected commit or version, steps to reproduce, impact, and a minimal proof of concept. Do not include live credentials or other people's personal data.

Please avoid public issues for vulnerabilities until a fix has been discussed. Test against a deployment and accounts you control.

The project is under active development. Fixes target the latest code on `main`; older snapshots are not maintained as separate security releases.

If you accidentally commit a credential, revoke or rotate it immediately. Removing it from the current file does not remove it from Git history. Contact the maintainer before publishing affected history.
